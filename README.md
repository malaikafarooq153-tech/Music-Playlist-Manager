# Music-Playlist-Manager
The Music Playlist Manager is a Java-based project that allows users to add, remove, search, sort, and play songs. It uses a Doubly Linked List to manage playlist songs and a Stack to store recently played songs. Its main features include displaying songs, alphabetical sorting, searching, and removing songs. It also allows users to view recent play history and undo the last play record. The project includes six default songs and demonstrates Linear Search, Bubble Sort, and basic data structure concepts.
